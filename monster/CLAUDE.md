# Monster Spray

Notes for Claude Code when working in this folder. Moved here from the root `CLAUDE.md` so they load only when needed.

**Monster Spray** (`monster/`, for `monster.kevintraywick.com`, 2026-09-29): a **standalone** Express static server (own `package.json`, NOT part of the Vite build), same shape as nyc2026 — `server.js` is `express.static('public')` + `/healthz` + a `no-cache` header for Safari. Three hand-written pages in `public/`: `index.html` (home, two links), `schedule.html` (weekly post deliverables for Kevin and Nick, first cut Oct 18 → fine cut Nov 1 → polish cut Nov 8 → final cut Dec 1). **The schedule is editable in the browser (2026-09-29, Kevin's pick: anyone with the link, no passphrase):** items are pills — drag one to another week or person (HTML5 DnD; `setData` so Safari starts the drag), click to edit in place (contenteditable `plaintext-only`, Enter/blur saves, Esc cancels, empty deletes), ✕ removes, + adds. State is `{people, weeks:[{end, label, items:{person:[{id,text}]}}]}` in **`DATA_DIR/schedule.json`** (`GET`/`PUT /api/schedule`, whole document, `rev` bumps per write, shape-checked server-side, `schedule-seed.json` is the fallback when the file is missing). The page re-reads every 20s while visible and only re-renders when `rev` changed and nothing is mid-edit. **Railway needs a volume at `/app/data` and `DATA_DIR=/app/data`** — without them every deploy resets the schedule to the seed. Every render goes through `esc()`; a `<img onerror>` pill was tested inert, `festivals.html` (the festival plan from Dec 1 on — deadlines, fees, city cards, top-tier and quirky tables; source of truth is `~/Documents/Claude/Projects/Kev Personal/monster-spray-festival-run.html`, copied here with a nav bar). Relative links only, so the pages also work from any subpath. Railway service **`monster`** (rootDir `monster`, watch `monster/**`) + custom domain — same CNAME + `_railway-verify.monster` TXT dance as nyc2026. Local: `cd monster && npm install && PORT=8874 node server.js`.
